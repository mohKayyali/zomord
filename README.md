# Zomord

Zomord is a proof of concept (PoC) exploring the use of generative AI in digital marketing and content creation. It demonstrates how AI can assist teams in producing, iterating on, and managing marketing content more efficiently.

## Overview

This project is an early-stage prototype built to validate ideas around AI-assisted content workflows. It is intended for experimentation and demonstration purposes rather than production use.

## Purpose

- Show how generative AI can streamline digital marketing tasks
- Explore AI-driven content creation and ideation
- Serve as a foundation for further product development

## Tech Stack

- TypeScript
- Vite
- Deployed on Vercel

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Live Demo

A deployed version is available at: https://zomord.vercel.app

## Status

This is a proof of concept and is under active exploration. Features and structure may change.
